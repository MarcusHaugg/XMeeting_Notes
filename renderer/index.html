Configurações

Transcrição

Fixar o idioma melhora a transcrição de falas curtas.

Resumo

O Ollama resume no seu computador, sem custo e sem enviar nada, mas com qualidade menor que as IAs na nuvem.

Chaves de IA

Assinaturas como ChatGPT Plus, Claude Pro ou o Gemini do Google Workspace não incluem a API. Para usar uma IA aqui, gere uma chave de API na conta dela: o consumo vai para essa conta.

Agenda e app

Fechar a janela não encerra o app: ele fica no ícone da barra para avisar das reuniões. Para fechar de vez, use "Sair do XMeeting" no menu do ícone.
